# Resume Portfolio Guide Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Create a practical Korean guideline document for writing strong developer resumes and portfolios for domestic hiring.

**Architecture:** Write one design document that fixes scope and structure, then create one reusable guideline document under `docs/`. Keep the guide organized around principles, section-by-section rules, portfolio structure, and checklists so it can be applied regardless of specific developer role.

**Tech Stack:** Markdown, Korean professional writing, resume/portfolio content strategy

---

**Files:**

**Step 1: Write the design summary**

### Task 2: Draft the guideline document

**Files:**
- Create: `docs/resume-portfolio-guidelines.md`

**Step 1: Write the core principles**

Explain the shared qualities of strong developer resumes and portfolios for Korean hiring contexts.

**Step 2: Write the resume structure guidance**

Cover header, summary, core skills, experience, projects, education, and optional supporting sections.

**Step 3: Write the portfolio structure guidance**

Cover introduction, representative projects, project write-up format, link strategy, and proof of work.

**Step 4: Add practical examples and templates**

Include good vs bad examples, bullet-writing formulas, and reusable templates.

### Task 3: Review and polish

**Files:**
- Review: `docs/resume-portfolio-guidelines.md`

**Step 1: Check practical usefulness**

Verify that each section can directly help rewrite a real resume or portfolio.

**Step 2: Check consistency**

Keep terminology, headings, and tone consistent across the document.

**Step 3: Check concision**

Trim repetition and ensure the guide is detailed but still skimmable.
