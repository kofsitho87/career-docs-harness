# Agent.md Design

**작성일:** 2026-03-07
**대상:** 이 저장소를 다루는 향후 에이전트 세션
**문서 목적:** `README.md`의 저장소 개요를 바탕으로, 에이전트가 빠르게 맥락을 이해하고 안전하게 작업할 수 있도록 온보딩 정보와 실행 지침을 함께 제공한다.

## 문제 정의

현재 `README.md`는 저장소의 목적과 구조를 설명하는 데 적합하지만, 에이전트가 실제 작업에 들어갈 때 필요한 우선순위와 수정 규칙은 충분히 담고 있지 않다.

- 어떤 문서를 먼저 읽어야 하는지
- 사실 수정과 표현 수정 중 어디를 먼저 바꿔야 하는지
- 어떤 디렉터리가 결과물이고 어떤 디렉터리가 근거 문서인지

이런 정보가 분리되어 있지 않으면 다음 세션의 에이전트가 불필요하게 탐색을 반복할 수 있다.

## 목표

- `README.md`의 구조와 설명을 유지한다.
- 에이전트 관점의 읽기 순서와 수정 우선순위를 명확히 한다.
- 사실 기준 문서, 가이드, 최종 산출물, 계획 문서, 자산의 역할을 한 번에 이해할 수 있게 한다.
- 작업 중 혼동하기 쉬운 규칙을 짧고 실용적으로 정리한다.

## 비목표

- `README.md`를 대체하는 일반 사용자용 소개 문서를 만들지 않는다.
- 새로운 작업 계획이나 기능을 추가하지 않는다.
- 기존 이력서/포트폴리오 본문을 수정하지 않는다.

## 제안 구조

1. 저장소 목적
2. 핵심 디렉터리와 역할
3. 우선 읽기 순서
4. 작업 원칙
5. 수정 우선순위
6. 주의사항

## 핵심 규칙

- 사실 변경은 먼저 `docs/source/origin-resume.md`
- 표현 개선은 `docs/guides/resume-guide.md` 확인 후 `resume/` 또는 `portfolio/` 수정
- 설계/계획 문서는 `docs/plans/`
- 이미지 자산은 `assets/`
- 현재 대표 산출물은 `resume/product-engineer.md`, `portfolio/outbound-voice-agent.md`
