# Visual QA

1. Render every slide at 1920×1080.
2. Inspect the contact sheet for hierarchy, rhythm, density, and theme consistency.
3. Inspect individual slides containing screenshots, dense text, diagrams, and closing links.
4. Require no clipping, horizontal overflow, missing assets, empty slides, unreadable contrast, or placeholder content.
5. Verify keyboard navigation, slide counter, alt text, and print media.
6. Reopen the PDF and confirm page count, 16:9 size, text extraction, and links.

Fix the outline when the communication goal is weak; fix components or theme tokens when several slides share the same visual defect.
