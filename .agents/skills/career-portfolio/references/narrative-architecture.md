# Narrative Architecture

## Narrative Question

The portfolio should answer: what recurring class of problem does this candidate solve, how do they solve it, and what evidence proves the pattern?

## Default Arc

1. Cover and professional identity
2. Career map or repeated problem pattern
3. Representative project context
4. Problem and constraints
5. System or product architecture
6. Key decision and tradeoff
7. Workflow or operating model
8. Evidence and result
9. Additional project or transferability
10. Personal role, learning, and closing

Adapt the arc to the available evidence. Merge weak slides instead of stretching them.

## Selection

- Prefer projects that strengthen the same positioning from different angles.
- Recent, high-ownership, evidence-rich work receives the most space.
- A project without clear personal contribution should not anchor the narrative.
- Career breadth belongs in a map; project depth belongs in focused slides.
